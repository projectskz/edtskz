# edtskz

## Конструктор бизнес-процессов (в разработке)
Тиражируемое расширение 1С (8.3.27 / 8.5) для ERP, УНФ, УТ, БП, КА, УХ: рисование схем процессов в пользовательском режиме, условия, оповещения, программируемые кнопки, возвраты на доработку, вложенные процессы, роли исполнителей с замещением.

- [Техническое задание](docs/ТЗ.md)
- [Архитектура](docs/Архитектура.md)
- [Анализ прототипа (KPI 3.1, ОТЭКО)](docs/АнализПрототипа.md)

## Архив
`Система_контроля_задачуправление_проектами/` — старый EDT-проект (8.3.14), к новому продукту не относится.
