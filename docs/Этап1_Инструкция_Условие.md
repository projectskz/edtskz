# Этап 1. Пошагово: задача с кнопками и Условие

Схема: Старт → Действие1 → Условие → Действие2 / Действие3 → Завершение.

Как это устроено:
- **Кнопки** настраиваются у задачи, после выполнения которой выбирается ветка (здесь «Действие1»).
- **Условие** ничего не спрашивает: смотрит, какой кнопкой выполнили «Действие1».
- У линий из Условия: у одной — «Результат задачи», у другой — «По умолчанию».

## 1. Схема

- Из Условия ровно две линии.
- Из «Действия2» и «Действия3» — линия на Завершение (одно общее или два).
- **Сохранить** → справа появятся шаги и линии.

## 2. Исполнители (каждая из трёх задач)

Выбрать задачу в списке справа → вкладка «Исполнители» → «Добавить»:
- **Способ** «Пользователь», **Пользователь** — обязательно выбрать (для теста — себя);
- либо **Способ** «Автор» (пользователь не нужен).

**Записать свойства.**

## 3. Кнопки у «Действия1»

Вкладка «Кнопки»:

| Кнопка | Вид | Прочее |
|---|---|---|
| Согласовать | Основная | пусто |
| Отклонить | Опасная | при желании «Коммент.» |

Колонку «Линия» не заполнять: она нужна, только если из задачи прямо выходит несколько линий. **Записать свойства.**

## 4. Линии из Условия

- «Условие → Действие2», вкладка «Линия»:
  - «Результат задачи» = «Действие1: Согласовать» (если списка нет — «Перечитать» и выбрать линию заново);
  - **Записать свойства**.
- «Условие → Действие3»:
  - отметить «По умолчанию»;
  - **Записать свойства**.

## 5. Запуск

«Проверить» (ошибок нет) → «Опубликовать» → «Запустить процесс» → «Мои задачи» → «Действие1»: кнопки «Согласовать» и «Отклонить».

## 6. Что проверить

| Действие | Ожидается |
|---|---|
| Действие1 → «Согласовать» | появилась «Действие2», в истории: Действие1 → Условие → Действие2 |
| Действие2 → «Выполнено» | процесс «Завершён» |
| Новый запуск, Действие1 → «Отклонить» | появилась «Действие3» |
| Действие3 → «Выполнено» | процесс завершён |

Без Условия: две линии прямо из «Действия1», кнопки не настраивать. Каждая линия станет кнопкой с заголовком = подписи линии (двойной щелчок по линии → «Наименование»).
